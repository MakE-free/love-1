# Love notes ♡

Милое адаптивное приглашение на свидание. Без сборки и зависимостей.

Запуск: `python3 -m http.server 3000 --bind 0.0.0.0` из каталога проекта.

Для общих фотографий положите исходный коллаж в `assets/collage.jpg`: сайт автоматически разделит его на три карточки. Кадрирование рассчитано на предоставленный скриншот 379 × 807 (работает и с пропорционально увеличенной копией). Также можно выбрать коллаж кнопкой на странице; этот вариант сохраняет фото только в текущем браузере. Чтобы получатель увидел фотографии, используйте файл `assets/collage.jpg` при публикации.

Кнопка согласия открывает поздравление; вторая кнопка позволяет подумать. Ответ никуда не отправляется. Шрифты загружаются из Google Fonts, предусмотрены системные замены.

Отдельные фотографии: `assets/portrait.jpg` — портрет, `assets/meow.jpg` — картинка «Я тебя мяумяу», `assets/moment.jpg` — фото у стены. Если эти файлы присутствуют, они заменяют заглушки соответствующих карточек.
