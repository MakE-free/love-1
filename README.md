# Кездесуге шақыру ♡

Қазақша интерактивті шақыру. Дизайн үлгісі: https://darkhankz.github.io/invitation/ .

Іске қосу: `python3 -m http.server 3000 --bind 0.0.0.0`. Жинақтау мен тәуелділіктер қажет емес.

Кездесу күні: 2026 жылғы 28 қазан. Кері санақ осы күннің басталуына дейін жүреді (UTC+05:00). Кездесу сағаты әлі келісілмеген; бетте «Уақытын келісеміз» деп көрсетіледі.

«Жоқ» батырмасы меңзерден және түртуден қашады. Бес әрекеттен кейін «Иә» батырмасының орнына тұрып, келісімді ашады. «Иә, әрине» бірден кездесу жоспарын көрсетеді. Жауап серверге жіберілмейді.

Бұрынғы үш фотосурет assets бумасында сақталған, жаңа үлгіде көрсетілмейді. GitHub Pages: main, / (root).
