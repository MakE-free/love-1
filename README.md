# Love notes ♡

Адаптивное приглашение на свидание с тремя оригинальными фотографиями. Без сборки и зависимостей.

Запуск из каталога проекта: `python3 -m http.server 3000 --bind 0.0.0.0`.

Фотографии включены в `assets/`: `portrait.jpg`, `meow.jpg`, `moment.jpg`. Они доступны всем посетителям сайта.

Кнопка согласия открывает поздравление; вторая кнопка позволяет подумать. Ответ никуда не отправляется. Шрифты загружаются из Google Fonts, предусмотрены системные замены.

GitHub Pages: ветка `main`, папка `/ (root)`.
